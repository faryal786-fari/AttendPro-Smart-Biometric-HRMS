System Users
Simple roles: View Only, Supervisor, and Super Admin.

👁 View Only User

Can view the dashboard and attendance, and export or print reports. Cannot edit attendance, change device settings, or manage users.

🧑‍💼 Supervisor

Includes all View Only permissions, plus attendance check-in/check-out and the ability to review and update attendance records.

🛡 Super Admin

Full access: add, switch, configure, and sync devices; create, update, and delete users; edit attendance; and manage reports.
